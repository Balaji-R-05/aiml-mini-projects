# Startup Profit Prediction (Multiple Regression)

Predicts startup profit from R&D spend, administration, marketing spend, and state (one-hot encoded) using multiple linear regression.

## Tech Stack
- Python, Scikit-learn, Pandas, Matplotlib

## Files
- `startup_prediction.ipynb` — encoding, training, and evaluation (MSE, R², MAE)
- `startups.csv` — dataset

## Run

```bash
jupyter notebook startup_prediction.ipynb
```
