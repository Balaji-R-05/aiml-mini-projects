# Laptop Price Prediction

Predicts laptop prices from specs (brand, type, RAM, screen, storage, etc.) with feature engineering and one-hot encoding on top of the raw dataset.

## Tech Stack
- Python, Pandas, Scikit-learn, Seaborn

## Files
- `main.ipynb` — data cleaning, feature engineering, and model training
- `laptop.csv` — dataset

## Run

```bash
jupyter notebook main.ipynb
```
