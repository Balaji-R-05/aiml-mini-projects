# Salary Prediction (Linear Regression)

Predicts salary from years of experience using a simple linear regression model.

## Tech Stack
- Python, Scikit-learn, Pandas, Matplotlib

## Files
- `main.ipynb` — training, evaluation (MAE, MSE, R²), and visualization
- `salary_data.csv` — dataset

## Run

```bash
jupyter notebook main.ipynb
```
