# AI Ping Pong

A simple Pong game built with Pygame, where the left paddle is AI-controlled and the right paddle is player-controlled.

## Tech Stack
- Python, Pygame

## Files
- `main.py` — game entry point and logic

## Run

```bash
python main.py
```

## Controls
- `Up` / `Down` arrow keys — move the right paddle
- `Space` — pause/resume
- First to 5 points wins
